# The Traveller

A whimsical, nature-themed travel website with destination packages.
Built with plain HTML, CSS and JavaScript (frontend only, no backend).

🔗 **Live Website: https://simran22m.github.io/the-traveller/**

## Project Overview
- **Idea:** A travel page that showcases dreamy destinations with sample
  package prices, in a calm, nature-inspired design.
- **Purpose:** To inspire people and help them discover and compare places
  for their next trip.
- **Target audience:** Students, young travellers and families planning trips.

## Features
- Floating navigation bar with a mobile hamburger menu
- Day / night theme toggle (the whole colour scheme changes)
- Parallax hero section with layered hills
- Image carousel with photos, arrows, dots and autoplay
- 6 destinations with starting package prices and what's included
- "Vibe picker" buttons that jump to a matching destination
- Save button with a live counter and Enquire button
- Flip cards for travel tips
- Scroll reveal animations
- Fully responsive on desktop and mobile

## Technology Stack
- HTML5 (structure)
- CSS3 (Flexbox, Grid, variables, animations, media queries)
- JavaScript (DOM manipulation, events, IntersectionObserver)
- GitHub Pages (deployment)

## Setup Instructions
1. Clone the repository:
   `git clone https://github.com/simran22m/the-traveller.git`
2. Open the `the-traveller` folder.
3. Open `index.html` in any web browser. No installation is required.

## What I Learned
I learned how HTML, CSS and JavaScript work together: HTML builds the page, CSS makes it look good and fit mobile screens, and JavaScript makes it interactive. I used CSS variables to switch between day and night mode, and built the carousel from a list of places so adding a new one is easy. I also learned how to put a website online using GitHub Pages.
